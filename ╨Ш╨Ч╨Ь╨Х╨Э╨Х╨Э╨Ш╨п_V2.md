# Небосвод — доработка v2

В этой версии:

- в начале сценария бот спрашивает **Мужчина / Женщина** и сохраняет выбор для грамматических форм;
- в текстах добавлены токены вида `[[мужская форма|женская форма]]`, которые автоматически подставляются перед отправкой сообщения;
- исправлены заметные женские формы, которые раньше попадали всем пользователям;
- добавлен второй слой расчёта — **баланс стихий и модальностей** по Солнцу, Луне, Меркурию, Венере, Марсу, Юпитеру, Сатурну и асценденту при известном времени;
- ответы по сферам больше не выводят цепочку почти одинаковых дат: повторные входы одной планеты склеиваются в **периоды**, а бот сначала выбирает разные планеты;
- для каждой пары «планета × сфера» теперь есть до четырёх более содержательных сценариев вместо двух коротких повторяющихся советов;
- раздел «Непрожитые жизни» переписан как понятная четырёхчастная структура: **ресурс → направление роста → сопротивление → действия**;
- убраны слабые примеры уровня «новая причёска / смена стиля» как центральное событие первого дома; акцент перенесён на идентичность, самостоятельность, границы и ответственность;
- добавлены более глубокие темы по всем 12 домам: финансы, договоры, семья, авторство, работа и здоровье, партнёрство, общие ресурсы, образование/релокация, карьера, сообщества, завершения и восстановление;
- оформление сообщений стало более структурным: короткие заголовки, нумерация слоёв, отдельные смысловые блоки и меньше «простыней» одинакового текста.

## Важное про `cities_data.json`

`astro_calc.py` в исходном проекте загружает файл `cities_data.json` из той же папки. В присланном наборе этого файла не было, поэтому я не создавал выдуманную замену. При обновлении проекта **оставьте ваш существующий `cities_data.json` рядом с `astro_calc.py`**.

## Какие файлы заменить

Замените в проекте:

- `bot.py`
- `content.py`
- `astro_calc.py`

`requirements.txt` не менялся. `avatar.png` оставлен тем же.

## Как добавлять новые склоняемые фразы

В `content.py` можно писать:

```python
"Вы [[готов|готова]] сделать следующий шаг."
```

Для мужчины бот отправит «Вы готов…», для женщины — «Вы готова…».
